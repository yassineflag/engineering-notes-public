# Embedded Linux

Notes on building and running Linux on embedded targets: bootloaders, kernel, root filesystems, Yocto/Buildroot, and on-target debugging.

## Notes

### Fundamentals

- [Cross-Compilation and Toolchains for Embedded Linux](fundamentals/cross-compilation-toolchain/cross-compilation-toolchain_v2_2026-11-08.md): a beginner's path from a PC to a C program on an Arm board: the concepts and terms, a working example with a shared library, Make and CMake, testing in QEMU, running on a BeagleBone Black or Raspberry Pi 4, then optional depth (glibc versions, CPU flags, sysroots, pkg-config, Meson, Autotools, choosing a toolchain, remote GDB) and troubleshooting by symptom.
- [Bootloaders for Embedded Linux: U-Boot](fundamentals/bootloader/bootloader_v2_2026-11-09.md): a beginner's path from power-on to a running kernel: what a bootloader does and how each board boots, building U-Boot, its command line and environment in QEMU, starting Linux by hand and automatically (boot scripts, extlinux.conf), U-Boot on a BeagleBone Black and a Raspberry Pi 4, then optional depth (load addresses, FIT images, device tree overlays, network boot, fw_setenv, safe updates and verified boot, GDB) and troubleshooting by symptom.
- [The Linux Kernel for Embedded Linux](fundamentals/kernel/kernel_v1_2026-11-10.md): from the bootloader's jump to `init` on a BeagleBone Black with Linux 7.1-rc1: what the kernel receives and must find, choosing a kernel, Kconfig and config fragments, building out of tree, the release string and module vermagic, installing on the SD card, the command line, the boot log stage by stage, the device tree from the kernel's side, root mounting, initramfs and init, modules and out-of-tree modules, keeping patches across releases, then debugging (earlycon, oops decoding, pstore, debugfs, ftrace), size and boot time, maintenance and hardening, arm64 and the Raspberry Pi 4, and troubleshooting by symptom.
- [Root Filesystems for Embedded Linux](fundamentals/rootfs/rootfs_v1_2026-11-11.md): from the kernel's `init` to a login prompt on a BeagleBone Black, building the root filesystem by hand: what the kernel needs and what PID 1 does, the directory layout, BusyBox, the C library and finding shared libraries, `/dev` with devtmpfs and mdev, BusyBox init with `inittab` and startup scripts, users, logins and file ownership (`fakeroot`), configuration (mounts, network, time, logs), images (ext4, squashfs, UBIFS, initramfs), SD card, eMMC and NFS root, then init systems compared, Debian, Buildroot and Yocto, cross-compiling packages into the tree, read-only roots and overlays, A/B updates, security and dm-verity, size, debugging `init` failures, arm64 and the Raspberry Pi 4, and troubleshooting by symptom.

### Linux build systems

- [The Yocto Project for Embedded Linux](linux-build-systems/yocto/yocto_v1_2026-11-14.md): from the concepts to a product image for a BeagleBone Black with Yocto 6.0 "Wrynose": BitBake, layers, recipes, machine, distro and image, the build machine, `bitbake-setup` and fragments, a first image in QEMU, the build directory, then your own layer, recipes and packages, the machine and the card, your own image and distribution configuration, append files, the kernel and the bootloader, `wic`, then BitBake syntax and overrides, `devtool`, the SDK, shared state, debugging a failed build, and production (reproducible builds, licenses, SBOM and CVE checks, hardening, updates), releases and what changed since 5.0, and troubleshooting by symptom.
