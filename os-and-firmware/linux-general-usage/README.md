# Linux General Usage

Notes on using Linux day to day: the shell, files, users and permissions, processes, services, packages, disks, devices and remote work.

## Notes

### Everyday Linux

- [Everyday Linux: The Shell, Files, Users, Packages and Services](everyday-linux/everyday-linux_v1_2026-11-16.md): the layers of a Linux system (kernel, userspace, distribution, shell) and "everything is a file", the terminal, keys and getting help (`man`, `--help`, `tldr`), the directory tree and paths, creating, copying, moving, deleting and linking files, wildcards and quoting, reading and editing text (`less`, nano, the vim minimum), finding files and text (`find`, `locate`, `grep`), users, groups and `sudo` (and the groups a development PC needs: `dialout`, `plugdev`), permissions, ownership, umask, special bits and ACLs, redirection, pipes and the text tools (`sort`, `cut`, `sed`, `awk`, `xargs`), variables, `PATH` and shell startup files, small Bash scripts with ShellCheck, processes, memory and signals, systemd services, drop-ins, timers and user units, the journal and `dmesg`, APT, repositories in deb822 format and backports, software outside APT (pipx, venvs, Flatpak, `/usr/local`, containers), disks, `fstab`, filesystems and writing SD card images safely, udev rules and the serial console, the network from the user's side, SSH keys and config, `rsync` and tmux, archives, checksums and backups, time, locale, updates and disk space, and troubleshooting by symptom.
