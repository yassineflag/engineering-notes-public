# Bash: A Quick Reference

A memory aid for writing and reading Bash scripts: the script skeleton, quoting, expansions, tests, loops, functions, arrays, redirection, text one-liners, traps, debugging and snippets to reuse. Each section is a few reminders and examples to copy, not a tutorial. For the shell as a user (files, permissions, `PATH`, startup files), see [Everyday Linux](../../os-and-firmware/linux-general-usage/everyday-linux/everyday-linux_v1_2026-11-16.md).

**Assumptions:** Bash 5.x (Debian 13 ships 5.2) with GNU coreutils, grep, sed and awk. On Debian, `/bin/sh` is dash, so these snippets need `bash`, not `sh`.

**Conventions:** `$` is a prompt; lines without it are script content. `# ->` shows the result. `<...>` is a value to replace.

**Verification status:** nothing here was run for this note. The snippets follow the Bash Reference Manual and the GNU tool manuals for Bash 5.2. They are illustrative and untested: run `shellcheck` on anything you copy.

## 1. Script skeleton and strict mode

```bash
#!/usr/bin/env bash
# name.sh: one line saying what it does.
set -euo pipefail

usage() { echo "usage: ${0##*/} [-v] FILE" >&2; exit 2; }

main() {
    [[ $# -ge 1 ]] || usage
    local file=$1
    echo "processing $file"
}

main "$@"
```

| Option | Effect | Watch out |
|---|---|---|
| `set -e` | Exit when a command fails | Ignored inside `if`, `while`, `&&`, `\|\|` and `!`. `local x=$(cmd)` hides the failure |
| `set -u` | Using an unset variable is an error | Write optional ones as `${var:-}` |
| `set -o pipefail` | A pipeline fails if any stage fails | `grep` with no match returns 1; `cmd \| head` can make `cmd` die of SIGPIPE (141) |

```bash
$ chmod +x name.sh && ./name.sh file.txt    # or: bash name.sh file.txt
$ bash -n name.sh                            # syntax check only
```

The script's own directory, wherever it is called from:

```bash
script_dir=$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)
```

## 2. Variables and quoting

```bash
name="world"              # no spaces around =
echo "hello $name"        # double quotes: expanded
echo 'hello $name'        # single quotes: literal
echo "${name}s"           # braces mark where the name ends
today=$(date +%F)         # command substitution (not backticks)
readonly MAX=10
export PATH="$HOME/bin:$PATH"   # export: visible to child processes
unset name
```

**Rule:** quote every expansion (`"$var"`, `"$(cmd)"`, `"$@"`) unless you want word splitting and globbing.

| Variable | Meaning |
|---|---|
| `$0` | Script name |
| `$1` … `$9`, `${10}` | Positional arguments |
| `$#` | Number of arguments |
| `"$@"` | All arguments, each one a separate word (use this one) |
| `"$*"` | All arguments joined into one string |
| `$?` | Exit status of the last command |
| `$$` | PID of the shell |
| `$!` | PID of the last background job |
| `$SECONDS`, `$RANDOM`, `$LINENO` | Seconds since start, random 0-32767, current line |

Prefer `printf` to `echo` for escapes, values that may start with `-`, and formatting:

```bash
printf '%s\n' "$var"
printf '%-10s %5d\n' "$name" "$count"
printf -v id '%03d' 7         # into a variable -> 007
nl=$'line1\nline2\ttab'       # ANSI-C quoting: \n, \t, \e work inside $'...'
```

## 3. Parameter expansion

Path tricks, with `f=/tmp/archive.tar.gz`:

| Expression | Result | Meaning |
|---|---|---|
| `${f##*/}` | `archive.tar.gz` | basename |
| `${f%/*}` | `/tmp` | dirname |
| `${f##*.}` | `gz` | extension |
| `${f%.*}` | `/tmp/archive.tar` | remove the shortest `.*` from the end |
| `${f%%.*}` | `/tmp/archive` | remove the longest `.*` from the end |
| `${f#*.}` | `tar.gz` | remove the shortest `*.` from the start |
| `${f/tmp/var}` | `/var/archive.tar.gz` | replace the first match |
| `${f//a/A}` | `/tmp/Archive.tAr.gz` | replace every match |
| `${#f}` | `19` | length |
| `${f:5:7}` | `archive` | substring: offset 5, length 7 |
| `${f^^}` / `${f,,}` | upper / lower case | |

Memory aid: `#` is on the left of `$` on the keyboard, so it cuts from the left; `%` cuts from the right. Doubled (`##`, `%%`) means the longest match.

Defaults and checks:

| Expression | Result |
|---|---|
| `${v:-def}` | `def` if `v` is unset or empty |
| `${v:=def}` | The same, and assigns `def` to `v` |
| `${v:+alt}` | `alt` if `v` is set and not empty, otherwise nothing |
| `${v:?message}` | Exits with `message` if `v` is unset or empty |
| `${!name}` | Value of the variable whose name is in `name` |

Without the `:` (`${v-def}`), only "unset" counts, not "empty".

Brace expansion builds words before anything else runs:

```bash
mkdir -p proj/{src,include,build}
echo {1..5} {01..03} {a..c}     # -> 1 2 3 4 5 01 02 03 a b c
cp config.ini{,.bak}             # -> cp config.ini config.ini.bak
```

## 4. Tests and conditionals

```bash
if [[ -f $file && -r $file ]]; then
    echo "readable file"
elif [[ -d $file ]]; then
    echo "directory"
else
    echo "missing: $file" >&2
fi
```

`[[ ]]` is Bash: no word splitting inside, with `&&`, `||`, patterns and regexes. `[ ]` is the POSIX `test` command: quote everything inside it.

| Files | | Strings | | Numbers | |
|---|---|---|---|---|---|
| `-e` | exists | `-z $s` | empty | `-eq` `-ne` | equal, not equal |
| `-f` | regular file | `-n $s` | not empty | `-lt` `-le` | less (or equal) |
| `-d` | directory | `==` `!=` | equal, not equal | `-gt` `-ge` | greater (or equal) |
| `-L` | symlink | `== *.log` | glob pattern (right side unquoted) | `(( a < b ))` | arithmetic test |
| `-r` `-w` `-x` | permissions | `=~` | regex | | |
| `-s` | not empty | `<` `>` | sort order | | |
| `a -nt b` | `a` newer than `b` | | | | |

```bash
if [[ $ver =~ ^([0-9]+)\.([0-9]+)$ ]]; then
    major=${BASH_REMATCH[1]} minor=${BASH_REMATCH[2]}
fi
```

Any command is a condition: exit status 0 is true.

```bash
if grep -q "error" app.log; then echo "errors found"; fi
if ! command -v jq >/dev/null; then echo "jq missing" >&2; exit 1; fi
mkdir -p out && cd out || exit 1
```

| Exit status | Meaning |
|---|---|
| `0` | Success |
| `1`, `2` | General error, usage error |
| `126` / `127` | Not executable / command not found |
| `128+N` | Killed by signal N: `130` Ctrl-C, `137` SIGKILL, `143` SIGTERM |

## 5. Loops and case

```bash
for f in *.log; do                 # glob, never $(ls)
    [[ -e $f ]] || continue        # no match leaves the literal "*.log"
    gzip -- "$f"
done

for i in {1..10}; do echo "$i"; done
for ((i = 0; i < 10; i++)); do echo "$i"; done
for arg in "$@"; do echo "$arg"; done

while IFS= read -r line; do echo "$line"; done < file.txt
until ping -c1 -W1 192.168.0.50 >/dev/null; do sleep 1; done
while true; do ...; break; done
```

`break` and `continue` take a count for nested loops: `break 2`.

```bash
case $1 in
    start|up)   start_service ;;
    stop)       stop_service ;;
    *.tar.gz)   tar xzf "$1" ;;
    -h|--help)  usage ;;
    *)          echo "unknown: $1" >&2; exit 2 ;;
esac
```

A quick menu:

```bash
select opt in build flash quit; do
    case $opt in
        build) make ;;
        flash) ./flash.sh ;;
        quit)  break ;;
    esac
done
```

## 6. Functions and arguments

```bash
greet() {
    local name=${1:?name required}    # local: does not leak to the caller
    local greeting=${2:-hello}
    echo "$greeting, $name"
}
greet "Ada"                # -> hello, Ada
msg=$(greet "Ada" hi)      # return data through stdout
```

- `return N` (0-255) returns a status, not data. Return data through stdout, or through a nameref.
- `shift` drops `$1`; `"$@"` passes all the arguments on unchanged.

A nameref (`local -n`) lets a function write into the caller's variables:

```bash
split_kv() {               # split_kv "key=value" KEYVAR VALVAR
    local -n _k=$2 _v=$3
    _k=${1%%=*}
    _v=${1#*=}
}
split_kv "port=8080" key val
echo "$key -> $val"        # -> port -> 8080
```

Short options with `getopts`:

```bash
verbose=0 out=out.txt
while getopts ":vo:h" opt; do      # o: takes a value; leading : = silent errors
    case $opt in
        v)  verbose=1 ;;
        o)  out=$OPTARG ;;
        h)  usage ;;
        :)  echo "-$OPTARG needs a value" >&2; exit 2 ;;
        \?) echo "unknown option -$OPTARG" >&2; exit 2 ;;
    esac
done
shift $((OPTIND - 1))              # "$@" now holds the non-option arguments
```

Long options, parsed by hand:

```bash
while [[ $# -gt 0 ]]; do
    case $1 in
        -v|--verbose) verbose=1; shift ;;
        -o|--output)  out=${2:?--output needs a value}; shift 2 ;;
        --output=*)   out=${1#*=}; shift ;;
        --)           shift; break ;;
        -*)           echo "unknown option $1" >&2; exit 2 ;;
        *)            break ;;
    esac
done
```

## 7. Arrays

```bash
files=(a.txt "b c.txt" d.txt)
files+=(e.txt)                    # append
echo "${files[0]}"                # first
echo "${files[-1]}"               # last
echo "${#files[@]}"               # count
echo "${files[@]:1:2}"            # slice: 2 elements from index 1
echo "${!files[@]}"               # indexes
for f in "${files[@]}"; do echo "$f"; done    # always "${arr[@]}", quoted
unset 'files[1]'                  # removes the element, leaves a gap in the indexes
```

Conversions:

```bash
mapfile -t lines < file.txt                  # file -> array, one line per element
mapfile -t srcs < <(find . -name '*.c')      # command output -> array
IFS=, read -ra parts <<< "a,b,c"             # split a string
joined=$(IFS=,; echo "${files[*]}")          # join with a comma
```

Build a command's arguments in an array, never in a string:

```bash
args=(-av --delete)
[[ $dry_run == 1 ]] && args+=(--dry-run)
rsync "${args[@]}" src/ dst/
```

Associative arrays (dictionaries):

```bash
declare -A port=([http]=80 [https]=443)
port[ssh]=22
echo "${port[https]}"                                  # -> 443
for k in "${!port[@]}"; do echo "$k=${port[$k]}"; done # order is not kept
[[ -v port[ftp] ]] || echo "no ftp"
```

## 8. Arithmetic

```bash
count=$((count + 1))
(( total = a * b + 2 ))
echo $(( 17 / 5 )) $(( 17 % 5 )) $(( 2 ** 10 ))    # -> 3 2 1024
echo $(( 0xff )) $(( 2#1010 )) $(( 8#17 ))         # -> 255 10 15
echo $(( (reg >> 4) & 0x0F ))                      # extract a bit field
printf '0x%04X\n' 4096                             # -> 0x1000
(( x > 5 )) && echo "big"
```

- Integers only. For decimals: `awk 'BEGIN { printf "%.2f\n", 10/3 }'` or `echo "scale=3; 10/3" | bc`.
- A leading zero means octal: `$(( 08 ))` fails. Force base 10 with `$(( 10#08 ))` (dates, times).
- `(( expr ))` returns status 1 when `expr` is 0. Under `set -e`, `(( i++ ))` with `i=0` ends the script: write `i=$((i + 1))`.

## 9. Redirection, pipes and here-docs

| Syntax | Effect |
|---|---|
| `cmd > f` / `cmd >> f` | stdout to `f` (truncate / append) |
| `cmd 2> f` | stderr to `f` |
| `cmd > f 2>&1` or `cmd &> f` | Both to `f` |
| `cmd 2>&1 \| less` or `cmd \|& less` | Both into the pipe |
| `cmd < f` | stdin from `f` |
| `cmd > /dev/null 2>&1` | Silence |
| `echo "msg" >&2` | Print to stderr |
| `cmd \| tee f` / `tee -a f` | Screen and file (append) |
| `echo x \| sudo tee /etc/f > /dev/null` | Write a root-owned file |

Order matters: `cmd > f 2>&1` puts both in `f`; `cmd 2>&1 > f` leaves stderr on the terminal.

Here-docs:

```bash
cat > app.conf <<EOF
host=$HOST
user=$(whoami)
EOF

cat <<'EOF'                  # quoted delimiter: nothing is expanded
literal $HOME and $(cmd)
EOF
```

`<<-EOF` strips leading tabs (not spaces), so the here-doc can be indented inside a function.

Here-string and process substitution:

```bash
grep -c "foo" <<< "$text"               # string as stdin
diff <(sort a.txt) <(sort b.txt)        # command output as a file
```

A pipe runs the loop in a subshell, so variables set inside it are lost:

```bash
n=0
grep "err" app.log | while read -r l; do n=$((n + 1)); done    # n is still 0 here
while read -r l; do n=$((n + 1)); done < <(grep "err" app.log)  # n is kept
```

Grouping:

```bash
{ date; uname -a; df -h; } > report.txt    # one redirect for several commands
( cd build && make )                        # subshell: the cd does not leak
```

Redirect the rest of the script, or open your own file descriptor:

```bash
exec > >(tee -a "$logfile") 2>&1   # from here on, all output goes to screen and log
exec 3> debug.txt                   # open fd 3
echo "trace" >&3
exec 3>&-                           # close fd 3
```

## 10. Reading input

```bash
read -rp "Name: " name
read -rsp "Password: " pass; echo                 # -s: no echo
read -rt 5 -p "Continue? [y/N] " ans || ans=n     # 5 s timeout
read -rn1 -p "Press a key " key                   # a single character
```

Line by line (`IFS=` keeps leading spaces, `-r` keeps backslashes):

```bash
while IFS= read -r line; do
    echo "$line"
done < file.txt

while IFS=: read -r user _ uid _; do      # split fields; _ discards
    echo "$user $uid"
done < /etc/passwd

while IFS=, read -r a b c || [[ -n $a ]]; do   # also reads a last line without a newline
    echo "$a | $b | $c"
done < data.csv
```

| Need | Snippet |
|---|---|
| Whole file into a variable | `content=$(< file.txt)` |
| File argument or stdin | `input=${1:-/dev/stdin}` |
| Is stdin a terminal? | `[[ -t 0 ]]` (stdout: `[[ -t 1 ]]`) |
| Names with spaces or newlines | `find . -print0 \| while IFS= read -r -d '' f; do ...; done` |

## 11. Text one-liners

grep:

```bash
grep -rn "TODO" src/                      # recursive, with line numbers
grep -rl --include='*.c' "malloc" .       # file names only
grep -v -e '^#' -e '^$' app.conf          # drop comments and blank lines
grep -E 'err(or)?|fail' app.log           # extended regex
grep -i -A3 -B1 "panic" dmesg.txt         # case-insensitive, with context
grep -oE '([0-9]{1,3}\.){3}[0-9]{1,3}' app.log | sort -u   # extract IPv4 addresses
```

sed:

```bash
sed 's/old/new/g' f                        # print the result
sed -i.bak 's/old/new/g' f                 # in place, keep f.bak
sed -n '10,20p' f                          # print lines 10 to 20
sed '/^#/d' f                              # delete comment lines
sed 's|/usr/local|/opt|g' f                # other delimiter for paths
sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin no/' /etc/ssh/sshd_config
```

awk:

```bash
awk '{ print $1, $3 }' f                           # columns 1 and 3
awk -F: '$3 >= 1000 { print $1 }' /etc/passwd      # filter on a field
awk '{ s += $2 } END { print s }' f                # sum a column
awk '{ c[$1]++ } END { for (k in c) print c[k], k }' access.log | sort -rn | head
awk 'NR == FNR { seen[$1]; next } !($1 in seen)' a.txt b.txt   # lines of b whose key is not in a
```

The rest:

```bash
sort | uniq -c | sort -rn | head          # top 10 most frequent lines
sort -t, -k3,3n data.csv                  # sort by the 3rd CSV column, numeric
cut -d: -f1,7 /etc/passwd                 # fields 1 and 7
tr -d '\r' < win.txt > unix.txt           # remove CRLF carriage returns
column -t -s, data.csv                    # align a CSV as a table
comm -12 <(sort a.txt) <(sort b.txt)      # lines common to both files
paste -sd+ numbers.txt | bc               # sum one number per line
jq -r '.items[].name' data.json           # JSON field

find . -name '*.o' -delete
find . -type f -mtime -1 -size +10M                # changed in 24 h, larger than 10 MB
find . -name '*.c' -print0 | xargs -0 grep -l "main("
find . -name '*.png' -exec optipng {} +            # + batches the files
xargs -P4 -n1 gzip < files.txt                     # 4 at a time
```

## 12. Errors, traps and cleanup

```bash
die()  { printf 'error: %s\n' "$*" >&2; exit 1; }
warn() { printf 'warning: %s\n' "$*" >&2; }

cd "$dir" || die "cannot cd to $dir"
rm -f stale.pid || true                       # allowed to fail under set -e
if ! out=$(make 2>&1); then die "build failed: $out"; fi
```

Clean up whatever happens:

```bash
tmp=$(mktemp -d)
cleanup() { rm -rf -- "$tmp"; }
trap cleanup EXIT                                  # normal end, exit N, set -e failure
trap 'echo "interrupted" >&2; exit 130' INT TERM   # the exit then runs the EXIT trap
```

Report where a script failed:

```bash
set -E     # errtrace: the ERR trap also fires inside functions
trap 'echo "line $LINENO: \"$BASH_COMMAND\" failed (status $?)" >&2' ERR
```

Status of every stage of the last pipeline: `make | tee build.log; echo "${PIPESTATUS[@]}"` → `2 0`.

## 13. Debugging

```bash
$ bash -n script.sh            # syntax check
$ bash -x script.sh            # trace every command
$ shellcheck script.sh         # static analysis: run it on every script
```

```bash
set -x; risky_part; set +x                                   # trace one block
export PS4='+ ${BASH_SOURCE##*/}:${LINENO}:${FUNCNAME[0]:-main}: '   # file:line:function in traces
[[ ${DEBUG:-0} == 1 ]] && set -x                             # DEBUG=1 ./script.sh
declare -p var arr             # show a variable exactly, with its type
printf '[%s]\n' "$var"         # reveal leading or trailing spaces
cat -A file                    # tabs as ^I, CR as ^M, line ends as $
type ll; command -v python3    # alias, function, builtin or which file
```

`$'\r': command not found` means the script has Windows line endings: `sed -i 's/\r$//' script.sh` (or `dos2unix`).

## 14. Processes, jobs and parallel work

```bash
long_task &                     # run in the background
pid=$!
wait "$pid"; echo "status $?"   # wait for it and get its status

task_a & task_b & wait          # run both in parallel, wait for all
timeout 10 cmd                  # kill after 10 s (status 124)
timeout -s KILL 30 cmd
kill -0 "$pid" 2>/dev/null && echo "still running"
nohup ./server.sh > server.log 2>&1 &    # survives logout (better: tmux or systemd)
time make -j"$(nproc)"
```

Interactive job control: `Ctrl-Z` suspends, `bg` resumes in the background, `fg %1` brings job 1 back, `jobs` lists them.

At most N jobs at once:

```bash
max=4
for f in *.wav; do
    flac -- "$f" &
    if (( $(jobs -rp | wc -l) >= max )); then wait -n; fi
done
wait
```

Only one instance at a time, with `flock`:

```bash
exec 9> /tmp/myscript.lock
flock -n 9 || die "already running"
```

## 15. Reusable snippets

```bash
# Timestamped log on stderr
log() { printf '%s %s\n' "$(date '+%F %T')" "$*" >&2; }

# Colors only when stdout is a terminal
if [[ -t 1 ]]; then red=$'\e[31m' green=$'\e[32m' reset=$'\e[0m'; else red='' green='' reset=''; fi
echo "${green}OK${reset} / ${red}FAIL${reset}"

# Required commands and root
for c in git jq curl; do command -v "$c" >/dev/null || die "missing command: $c"; done
(( EUID == 0 )) || die "run as root"

# Ask before doing something dangerous
confirm() { local a; read -rp "$1 [y/N] " a; [[ $a == [yY]* ]]; }
confirm "Write the image to /dev/sdX?" || exit 1

# Retry with exponential backoff: retry CMD ARGS...
retry() {
    local n=0 max=5 delay=1
    until "$@"; do
        n=$((n + 1))
        if (( n >= max )); then return 1; fi
        sleep "$delay"; delay=$((delay * 2))
    done
}
retry curl -fsS http://192.168.0.50/health

# Wait for a condition, with a timeout: wait_for SECONDS CMD ARGS...
wait_for() {
    local end=$((SECONDS + $1)); shift
    until "$@"; do
        (( SECONDS < end )) || return 1
        sleep 1
    done
}
wait_for 60 ssh -o ConnectTimeout=2 root@192.168.0.50 true

# Read a key=value file without executing it (unlike `source`)
declare -A cfg
while IFS='=' read -r k v; do
    [[ $k =~ ^[[:space:]]*(#|$) ]] && continue     # skip comments and blank lines
    cfg[$k]=$v
done < app.conf
echo "${cfg[host]:-localhost}"

# Dated backup copy and elapsed time
cp -a -- "$f" "$f.$(date +%Y%m%d-%H%M%S).bak"
start=$SECONDS; make; echo "took $((SECONDS - start)) s"
```

## 16. Interactive shell

| Keys | Action |
|---|---|
| `Ctrl-R` | Search history (again to go further back) |
| `Ctrl-A` / `Ctrl-E` | Start / end of the line |
| `Alt-B` / `Alt-F` | One word back / forward |
| `Ctrl-W` / `Alt-D` | Delete the word before / after |
| `Ctrl-U` / `Ctrl-K` | Delete to the start / end of the line |
| `Alt-.` | Insert the last argument of the previous command |
| `Ctrl-X Ctrl-E` | Edit the command line in `$EDITOR` |
| `Ctrl-L` / `Ctrl-C` / `Ctrl-D` | Clear / interrupt / end of input (logout) |

| History | Meaning |
|---|---|
| `!!` | Last command (`sudo !!`) |
| `!$` / `!*` | Last argument / all arguments of the last command |
| `!git` | Last command starting with `git` |
| `^old^new` | Rerun the last command with `old` replaced by `new` |
| `cd -` | Back to the previous directory |

Globs:

| Pattern | Matches |
|---|---|
| `*` `?` `[abc]` `[0-9]` | Any string, one character, one from a set |
| `**/*.c` | Recursive (needs `shopt -s globstar`) |
| `*.@(jpg\|png)` `!(*.o)` | Alternatives, negation (`shopt -s extglob`) |
| `shopt -s nullglob` | A glob with no match expands to nothing |
| `shopt -s dotglob` | `*` also matches hidden files |

In `~/.bashrc`:

```bash
HISTSIZE=100000
HISTFILESIZE=200000
HISTCONTROL=ignoreboth:erasedups      # no duplicates, no lines starting with a space
HISTTIMEFORMAT='%F %T '
shopt -s histappend globstar
alias ll='ls -alF' gs='git status' ..='cd ..'
mkcd() { mkdir -p -- "$1" && cd -- "$1"; }
```

## 17. Pitfalls

| Wrong | Right | Why |
|---|---|---|
| `x = 5` | `x=5` | With spaces, `x` runs as a command |
| `for f in $(ls *.txt)` | `for f in *.txt` | Names with spaces get split |
| `rm -rf $dir/` | `rm -rf -- "${dir:?}/"` | An empty `$dir` turns it into `rm -rf /` |
| `cd dir; rm *` | `cd dir \|\| exit; rm -- *` | If `cd` fails, `rm` runs in the wrong place |
| `[ $a == b ]` | `[[ $a == b ]]` | An empty `$a` gives a syntax error |
| `if [ grep -q x f ]` | `if grep -q x f` | `if` tests a command; `[` is just one command |
| `cat f \| while read l; do n=...` | `while read -r l; do ...; done < f` | The pipe runs the loop in a subshell |
| `local out=$(cmd)` | `local out; out=$(cmd)` | `local` hides `cmd`'s exit status |
| `sort f > f` | `sort -o f f` or a temporary file and `mv` | `>` empties `f` before `sort` reads it |
| `sudo echo x > /etc/f` | `echo x \| sudo tee /etc/f > /dev/null` | Your shell, not root, opens the redirect |
| `ssh host cmd` inside `while read` | `ssh -n host cmd` | `ssh` swallows the loop's stdin |
| `(( i++ ))` under `set -e` | `i=$((i + 1))` | Returns status 1 when `i` was 0 |
| `$(( 08 ))` | `$(( 10#08 ))` | A leading 0 means octal |
| `#!/bin/sh` with `[[ ]]` or arrays | `#!/usr/bin/env bash` | `sh` is dash on Debian |
| `echo $var` | `printf '%s\n' "$var"` | Splitting, globbing, and values like `-n` |
